# 日越英 相互最高峰翻訳アプリ (Hệ Thống Dịch Thuật Nhật - Việt - Anh Đỉnh Cao)

ベトナム人と日本人のコミュニケーション専用に設計された、Google翻訳を凌駕する高精度・高速かつ完全無料枠で動作する翻訳Webアプリケーションです。

---

## 🌟 主な特長 (Đặc điểm nổi bật)

1. **英語経由（Pivot Bridge）の必須パイプライン**:
   - ベトナム語と日本語を直接翻訳せず、**必ず英語を中間言語として経由**することで、直接対訳特有の不自然さや敬語・人称代名詞の歪みを徹底排除。
   - **日本語入力時**: `日本語 ➔ 英語（中間訳） ➔ ベトナム語` を実行し、【ベトナム語】と【英語】を出力。
   - **ベトナム語入力時**: `ベトナム語 ➔ 英語（中間訳） ➔ 日本語` を実行し、【日本語】と【英語】を出力。
   - **英語入力時**: 【ベトナム語】と【日本語】の2言語を出力。
2. **原文の完全フォーマット保持**:
   - 段落（空行）、改行、番号リスト（`1.`, `2.`）、記号箇条書き（`-`, `*`）、インデントを100%保持。
3. **2言語のワンクリック コピー＆ペースト**:
   - それぞれの出力結果に独立した「コピー（Sao chép）」ボタンを設置。1クリックで改行を保持したままクリップボードへコピー可能。
4. **Google Gemini 2.5 Flash / 2.0 Flash 無料枠連携**:
   - クレジットカード不要で完全無料の Google AI Studio API を活用。
   - 秒間100トークン以上の超高速レスポンスと、Google翻訳を超える自然な文脈理解を実現。
5. **文体・トーン切替**:
   - 「ビジネス・丁寧語（Lịch sự / Công việc）」と「日常・カジュアル（Thân mật / Hàng ngày）」をワンクリック切替。
6. **Web Speech API による音声発音 (TTS)**:
   - 日本語・ベトナム語・英語のネイティブ音声読み上げに対応。
7. **ローカル履歴機能**:
   - 過去の翻訳内容をブラウザに自動保存。

---

## 🚀 起動方法 (Cách khởi chạy)

本プロジェクトディレクトリで以下のコマンドを実行します：

```bash
# 依存パッケージのインストール
npm.cmd install

# 開発サーバーの起動
npm.cmd run dev
```

起動後、ブラウザで `http://localhost:5173` を開いてください。

---

## 🔑 Google AI Studio 無料APIキーの取得手順 (1分・完全無料)

本アプリはAPIキー未設定でもサンプルデモ翻訳を試すことができますが、実際の高精度AI翻訳を利用するには無料キーを設定してください：

1. [Google AI Studio (https://aistudio.google.com/app/apikey)](https://aistudio.google.com/app/apikey) にアクセスします。
2. Googleアカウントでログインします（※クレジットカードの登録は不要です）。
3. **「Create API key」** をクリックしてキーを生成します。
4. アプリ右上の **「APIキー設定」** ボタンを押し、コピーしたキーを貼り付けて「保存」を押します。
